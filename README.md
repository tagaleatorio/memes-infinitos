# Memes Infinitos RPG

RPG de turnos com os personagens do Melk, em pixel art.

## Baixar no celular (Android)

1. Abra a página **Releases** deste repositório (menu à direita, ou `/releases/latest`).
2. Baixe o arquivo **Memes-Infinitos.apk**.
3. Abra o arquivo no celular. O Android vai pedir para permitir instalar apps desta fonte: permita e toque em **Instalar**.

Cada vez que o jogo é atualizado aqui, um APK novo é gerado sozinho. Ele instala por cima do antigo e mantém o progresso.

## Jogar no computador

Abra `app/src/main/assets/www/index.html` no navegador (as duas músicas precisam ficar na mesma pasta).
